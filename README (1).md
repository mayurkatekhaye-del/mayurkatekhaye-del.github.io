# Mayur Katekhaye — Personal Portfolio

A responsive personal portfolio website built with **HTML, CSS, and JavaScript**. It introduces my background as a B.Tech CSE student at NIAT College, lists my skills, showcases selected projects, and provides ways to contact me.

## Live Website

After enabling GitHub Pages, the site should be available at:

**https://mayurkatekhaye-del.github.io/**

This is the expected URL for the `mayurkatekhaye-del.github.io` repository; it will work after the files are pushed and GitHub Pages finishes deploying.

## Features

- Dark purple neon visual theme
- Responsive layout for desktop, tablet, and mobile
- Sections for About, Education, Skills, Projects, and Contact
- Mobile navigation menu
- Links to GitHub, LinkedIn, and project repositories/live demos
- Keyboard-visible focus styles and reduced-motion preference support
- No framework or build tools required

## Technologies

- HTML5
- CSS3 (Grid, Flexbox, media queries, gradients, transitions)
- Vanilla JavaScript

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser such as Chrome, Edge, Firefox, or Safari.
3. No package installation or build step is necessary.

## Deploy with GitHub Pages

1. Create a public repository named **`mayurkatekhaye-del.github.io`** under the GitHub account `mayurkatekhaye-del`.
2. Upload `index.html` and `README.md` to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **`main`** and folder **`/(root)`**, then save.
6. Wait for the deployment to finish, then visit `https://mayurkatekhaye-del.github.io/`.
